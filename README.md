# بطاقات المفردات — نشر على Vercel

## الملفات
- `index.html` — الموقع نفسه (صفحة واحدة، بدون خطوة بناء/build)
- `api/check.js` — دالة سيرفرلس (Serverless Function) تتحقق من الترجمة عبر Anthropic API، وتُبقي مفتاح الـ API على السيرفر فقط ولا يظهر أبداً في المتصفح
- `package.json` — ملف بسيط يعرّف المشروع لـ Vercel

## خطوات النشر

1. ارفع هذا المجلد كامل (بكل ما فيه: `index.html`, `api/check.js`, `package.json`) إلى مشروع جديد على [vercel.com](https://vercel.com) — إما بالسحب والإفلات مباشرة، أو عبر ربطه بمستودع GitHub، أو عبر الأمر `vercel` من الطرفية داخل المجلد.
2. **مهم جداً:** بعد إنشاء المشروع، روح لـ **Settings → Environment Variables** وأضف متغير باسم:
   ```
   ANTHROPIC_API_KEY = sk-ant-...
   ```
   (احصل على المفتاح من [console.anthropic.com](https://console.anthropic.com))
3. اعمل **Redeploy** بعد إضافة المتغير (Vercel ما يطبّق متغيرات جديدة إلا بعد إعادة نشر).
4. افتح الرابط اللي يعطيك ياه Vercel — التطبيق والتحقق بالذكاء الاصطناعي بيشتغلون مباشرة.

## ماذا لو نسيت إضافة المفتاح؟
التطبيق ما راح ينكسر — بيرجع تلقائياً لنظام تحقق محلي متساهل (يتجاهل التشكيل، الأخطاء الإملائية القريبة، والمرادفات) بدون أي إعداد إضافي. بس ميزة تقييم الذكاء الاصطناعي الكاملة تحتاج المفتاح.
